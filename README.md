# 🧠 Basic Memory Game (Temel Hafıza Oyunu)

[![Python](https://img.shields.io/badge/Python-3.x-blue.svg)](https://www.python.org/)
[![Pygame](https://img.shields.io/badge/Game-Pygame-green.svg)](https://www.pygame.org/)

[TR] Python ve Pygame kütüphanesi kullanılarak geliştirilmiş, görsel hafızayı test eden kart eşleştirme oyunu. Modern ve sade bir arayüz sunar.

[EN] A card matching game designed to test visual memory, developed using Python and the Pygame library. It features a modern and minimalistic interface.

---

## ✨ Features / Özellikler

- **[TR] Kart Eşleştirme:** Zamanla yarışarak benzer kartları bulmaya çalışın.
- **[EN] Card Matching:** Race against time to find pairs of matching cards.
- **[TR] Skor Sistemi:** Hatalı denemeleri ve geçen süreyi takip edin.
- **[EN] Score System:** Track incorrect attempts and the elapsed time.
- **[TR] Grafik Arayüz:** Pygame ile akıcı animasyonlar ve görseller.
- **[EN] Graphic UI:** Smooth animations and visuals with Pygame.

---

## 🚀 Setup & Run / Kurulum ve Çalıştırma

### [TR] Adımlar
1. Gerekli kütüphaneleri yükleyin: `pip install pygame`
2. Çalıştırın: `python main.py`

### [EN] Steps
1. Install dependencies: `pip install pygame`
2. Run: `python main.py`
