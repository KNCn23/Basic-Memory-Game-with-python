# Memory Game

A card-matching memory game built with Python and Pygame. Flip cards to find matching pairs before time runs out.

## Features

- Grid-based card layout with face-down/face-up flip animation
- Timer and attempt counter tracked per session
- Randomized card placement on each new game
- Clean Pygame interface

## Run

```bash
pip install pygame
python main.py
```

Requires Python 3.8+.
